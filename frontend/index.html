About AI Music Generator
Deep Learning LSTM

AI Music Generator Using Deep Learning (LSTM) is an intelligent end-to-end web application that models polyphonic musical structures, harmonic chords, and melody progressions. Built with Python, Flask, Music21, PrettyMIDI, and Long Short-Term Memory (LSTM) Recurrent Neural Networks.

Neural Network Architecture
  • Recurrent Memory Cells: Dual hidden state $(h_t)$ and cell memory state $(C_t)$ retain long-term thematic coherence over sequences.
  • Triple Gating Mechanism: Forget gate $(f_t)$, Input gate $(i_t)$, and Output gate $(o_t)$ regulate melodic patterns.
  • Adam Optimization: Adaptive moment estimation ensures stable loss reduction through sequence gradients.
  • Temperature Sampling: Controls probability entropy to balance harmony and artistic creativity.
Technology Stack
Python 3.14 Flask REST API TensorFlow / Keras NumPy & Pandas music21 PrettyMIDI FluidSynth HTML5 / Web Audio API Chart.js Bootstrap 5

Full polyphonic and monophonic synthesis pipeline with real-time waveform visualization in the browser.

End-to-End System Pipeline

1. Dataset Collection

Multi-genre MIDI ingestion (Classical, Jazz, Piano, Instrumental) with pitch and instrument validation.

2. Data Preprocessing

music21 stream extraction, chord dot-representation, duration quantization, and sequence windowing.

3. LSTM Development

Multi-layer LSTM architecture with backpropagation through time and live loss visualization.

4. AI Music Generation

Softmax temperature sampling generates original token sequences step-by-step from seed patterns.

5. MIDI Conversion

Re-encodes generated tokens into music21 streams, assigns velocities and instruments, and exports .mid.

6. Audio Synthesis & Playback

Renders WAV audio via FluidSynth and PrettyMIDI with interactive waveform and piano roll playback.
